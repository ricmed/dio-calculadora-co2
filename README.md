# 🌿 Calculadora de Emissões de CO₂

## Visão Geral

Uma calculadora web moderna e intuitiva para calcular o impacto ambiental das suas viagens, desenvolvida com foco em sustentabilidade e interface de usuário aprimorada.

## 🎯 Funcionalidades

✅ **Cálculo de Emissões de CO₂**
- Calcule as emissões com base no tipo de transporte e distância
- Suporte para múltiplos meios de transporte (bicicleta, carro, ônibus, caminhão)
- Dados de rotas pré-configuradas para as principais cidades brasileiras

✅ **Comparação de Transportes**
- Visualize como diferentes meios de transporte se comparam
- Gráficos interativos mostrando o impacto relativo
- Dicas para reduzir sua pegada de carbono

✅ **Créditos de Carbono**
- Calcule a quantidade de créditos necessários para compensar
- Estimativa de preço em reais brasileiros
- Informações sobre como investir em compensação ambiental

✅ **Interface Moderna**
- Design responsivo com suporte para mobile, tablet e desktop
- Efeitos glassmorphism e animações suaves
- Tema eco-friendly com gradientes verdes
- Tema claro para melhor legibilidade

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilos modernos com variáveis CSS
- **JavaScript (Vanilla)** - Lógica sem dependências externas

## 🚀 Como Usar

Visit: https://ricmed.github.io/dio-calculadora-co2

### Instalação Local

```bash
# Clone o repositório
git clone https://github.com/ricmed/dio-calculadora-co2.git

# Navegue para a pasta
cd dio-calculadora-co2

# Abra o arquivo index.html no seu navegador
open index.html
```

## 📝 Como Funciona

1. **Selecione as cidades**: Digite a origem e o destino de sua viagem
2. **Confirme a distância**: A aplicação encontra automaticamente a distância ou você pode inserir manualmente
3. **Escolha o transporte**: Selecione o meio de transporte que será utilizado
4. **Visualize os resultados**: Veja as emissões calculadas, comparações e opções de compensação

## 🌍 Impacto Ambiental

Esta calculadora ajuda você a:
